# data_visualization_project
This project displays a data visualization project for MSDS.

 Wine Dataset Visualization Project

Overview

This project explores the Wine dataset included with scikit-learn. It uses Python, Pandas, NumPy, Matplotlib, and Jupyter Notebook to examine the chemical characteristics of three wine classes and communicate meaningful patterns through data visualization.

The completed notebook includes both the Python code and rendered output, making it ready to view directly on GitHub.

Project Objectives

Load and inspect a real-world dataset

Evaluate data quality and descriptive statistics

Compare the distribution of wine classes

Visualize feature distributions and class differences

Explore relationships between chemical measurements

Identify highly correlated features

Summarize insights that could support future machine-learning work
