# 🍷 Wine Data Visualization with Python

## Overview

This repository showcases a comprehensive data visualization project using the **Wine dataset** from the Scikit-learn library. The project demonstrates how visualization techniques can be used to explore, understand, and communicate insights from a real-world dataset.

The notebook walks through the complete visualization process, from loading and exploring the data to creating multiple charts that reveal relationships, trends, and patterns among wine characteristics.

---

## Project Objectives

The goals of this project are to:

- Load and explore a real-world dataset
- Perform exploratory data analysis (EDA)
- Create informative data visualizations
- Identify relationships between variables
- Compare feature distributions
- Analyze correlations among variables
- Practice data storytelling through visualization

---

## Dataset

The project uses the **Wine Dataset** included with Scikit-learn.

The dataset contains chemical analysis measurements for wines from three different cultivars.

### Features Include

- Alcohol
- Malic Acid
- Ash
- Alcalinity of Ash
- Magnesium
- Total Phenols
- Flavanoids
- Nonflavanoid Phenols
- Proanthocyanins
- Color Intensity
- Hue
- OD280/OD315
- Proline

**Records:** 178

**Features:** 13

**Classes:** 3 Wine Categories

## Visualizations Included

This project includes several exploratory visualizations:

### 📊 Class Distribution

Shows the number of wine samples in each class.

---

### 📈 Alcohol Distribution Histogram

Displays the distribution of alcohol content across all wine samples.

---

### 📦 Proline Box Plot

Visualizes the spread, quartiles, and potential outliers for Proline.

---

### 🔵 Scatter Plot

Alcohol vs. Color Intensity

Used to identify relationships between these two variables.

---

### 📉 Correlation Heatmap

Displays correlation coefficients among all numerical variables.

Helps identify:

- Strong positive relationships
- Strong negative relationships
- Features that move together

---

### 📋 Correlation Summary

A table listing the strongest positive and negative feature correlations.

## Key Findings

Some insights from the analysis include:

- Wine classes have different distributions across chemical properties.
- Alcohol content varies noticeably between wine samples.
- Several features exhibit strong positive correlations.
- Some chemical measurements are negatively correlated.
- Visualizations make it easier to identify trends and potential outliers than summary statistics alone.
